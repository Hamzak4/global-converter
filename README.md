ConvertHub Project Description
Project Overview
ConvertHub is a professional, full-stack unit and currency converter platform with an integrated admin dashboard, SEO-optimized content management, and real-time analytics. It's designed as both a user-facing conversion tool and an administrative platform.

Technology Stack

Frontend
React 19 + TypeScript for the UI
Vite 5.4 for fast builds and development
TailwindCSS 4.3 for styling
Lucide React for icons
Motion 11.11 for animations
Recharts 2.13 for data visualization

Backend
Express 4.21 (Node.js) REST API server
MySQL 8+ for production database
JSON file (db.json) for local/fallback storage
CORS enabled for cross-origin requests

Build & Deployment
Development: tsx for TypeScript execution
Production: Vite (frontend) + esbuild (backend bundling)

Core Features
🔄 Conversion Tools
Currency Converter - Real-time exchange rates
Unit Converters:
Length (meters, km, miles, yards, feet, inches)
Weight (kg, grams, pounds, ounces, stone, tons)
Temperature (Celsius, Fahrenheit, Kelvin)
Area and Volume conversions
Conversion history & logging

📚 Content Management
SEO-optimized blog articles with conversion formulas
FAQ system organized by category
Multi-language support (English, Spanish, Urdu)
Dark mode toggle

👨‍💼 Admin Dashboard
User authentication & password recovery
Visitor analytics (IP tracking, browser detection, page visits)
Customizable site settings (branding, company info, ads)
Article & FAQ management
Exchange rate updates
Google Analytics integration ready
